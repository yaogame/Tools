# 生成分级练习牌库

App 里的 `BridgeReplay/Resources/PracticeDeals.json` 由这里的脚本生成：随机发牌，用 DDS（通过 Python 包 `endplay`）做双明手分析，再按难度分级。

```bash
pip install endplay
python3 build_pool.py      # 约 2 分钟，生成 PracticeDeals.json
```

## 怎么分级

- **坐庄**：定约取这副牌的最优定约（par，不含牺牲叫），双明手下都能完成。沿双方都最优的打法走一遍，在庄家和明手每一次出牌时，看"常规打法"（第二家小、第三家大、先兑现大牌、先清将）出的那张牌会不会让定约失败。会失败的次数就是"关键决定"数：
  - 初级：0 个
  - 中级：1 个
  - 高级：2–3 个
  - 大师级：4 个以上
- **防守**：定约比双明手能做成的高一阶，所以最优防守正好打宕一墩。你坐庄家左手（首攻）。按同样方法数你这一家的关键决定：
  - 初级：0 个
  - 中级：1 个
  - 高级：2 个
  - 大师级：3 个以上
- **叫牌**：南北合计至少 20 点，附双明手墩数表和南北能得的最高分。

现在每级数量：坐庄每级 50 副（共 200 副），防守每级 30 副（共 120 副），叫牌 100 副。要改数量，改 `build_pool.py` 里的 `want`。
