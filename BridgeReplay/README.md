# 坐庄复盘（iOS）

线下坐庄没打成的那副牌，录进来，在手机上重新坐庄。

## 功能

App 底部有五个标签页：

- **复盘**：线下没打成的牌拿到线上重新坐庄。
  - 录入：拍照或从相册选一张四家摊开的照片，手机本地自动识别（不联网、不要 Key）；确认「照片上方是哪一家」后一键填入。也可以手动点选或粘贴 PBN / BBO LIN。
  - 看不清的牌按排除法补上并标黄，识别重复的标红，都可以再点选修改。
  - 定约手动录入；可以补录线下已出的牌作为「恢复点」，从出错的那一墩接着打。
- **坐庄**：分级练习。初级、中级、高级、大师级各 50 副，都是随机生成、用双明手分析分级的牌。
- **防守**：分级练习。每级 30 副，每副都是最优防守正好打宕一墩；你坐庄家左手首攻，庄家和同伴由机器人按双明手打。
- **叫牌**：按专题练习，叫牌体系是自然制（五张高花、1NT 15–17 点、强 2♣、弱二）。
  - 专题：1 阶高花开叫、1 阶低花开叫、1NT 开叫、强开叫（2♣ / 2NT）、阻击开叫（弱二 / 三阶），各 30 副；另有综合练习 100 副。
  - 你叫南北两手（东西不叫）。北家开叫后马上告诉你开叫对不对、为什么。
  - 叫完按双明手墩数表打分，给出最佳定约，可以直接去坐庄。
- **牌例**：在牌桌上或牌局详情里「保存为牌例」，加标题和备注；之后从保存的位置接着练，也能分享 PBN。

出牌时：
- **每墩后可得墩数**：顶部「可得」和底部 13 格走势，显示双明手下你这一方最终能拿几墩，丢墩的格子标红点。
- **每张牌的墩数**：打开「每张牌墩数」后，每张可出的牌上都标出出这张后你方最终能拿的墩数。
- **机器人和手工**：机器人防守分「常规」和「最强」（双明手最优）。在「更多 → 手工出牌」里可以把任意一家机器人改成由你手工出牌。
- **复盘**：列出每一张让你方丢墩或对方送墩的牌，可以从任意一墩重打。

## 一键运行（推荐）

在终端运行（路径换成你解压的位置）：

```bash
bash ~/Downloads/BridgeReplay/一键运行.command
```

脚本会先去掉下载文件的隔离标记（之后在访达里双击也能运行），然后让你选：

1. 打开 Xcode 并直接运行，用 Xcode 顶部选中的模拟器或 iPhone（默认）。第一次会问「终端想要控制 Xcode」，点「好」。
2. 在模拟器里编译运行：不需要签名，编译错误直接显示在终端。
3. 装到连接的 iPhone（同下面的安装脚本）。
4. 只用 Xcode 打开工程。

## 一键安装到 iPhone

1. iPhone 用数据线连上 Mac，解锁手机，点「信任此电脑」。
2. 打开开发者模式：iPhone「设置 → 隐私与安全性 → 开发者模式」，打开后按提示重启手机。
3. 在 Xcode →「Settings → Accounts」里登录 Apple ID（免费账号也可以）。
4. 在「终端」里运行（把路径换成你解压的位置）：

   ```bash
   xattr -dr com.apple.quarantine ~/Downloads/BridgeReplay
   bash ~/Downloads/BridgeReplay/安装到iPhone.command
   ```

   从网上下载的 zip 会被 macOS 加上「隔离」标记，所以直接双击会提示 “Apple could not verify…”。
   第一行命令去掉这个标记，之后在访达里双击也能运行。用 git clone 下来的工程没有这个标记，可以直接双击。

脚本会依次自动完成：找到手机、编译、签名、安装、打开 App。还会在 `build/BridgeReplay.ipa` 生成一个安装包。

注意：
- **第一次打开前要信任开发者**：在 iPhone「设置 → 通用 → VPN与设备管理」里信任你的 Apple ID。
- **免费账号 7 天后失效**：用免费 Apple ID 装的 App 7 天后会失效，再双击脚本重装即可，牌局数据不会丢。

## 用 Xcode 运行

1. 用 Xcode 16 或更新版本打开 `BridgeReplay.xcodeproj`。
2. 选一个 iPhone 模拟器，按 ⌘R 运行。
3. 装到真机上时，在 Signing & Capabilities 里选择你自己的 Team。

最低支持 iOS 17，只做了 iPhone 竖屏。

## 照片识别是怎么做的

全部在手机上完成（`Core/OnDeviceCardReader.swift`）：

1. 找出牌角的小花色符号，按颜色分红黑。
   - 红色：看形状上下是否对称。♥ 上宽下尖，♦ 上下对称。
   - 黑色：看轮廓的凹口数量。♣ 有 3 个以上，♠ 只有 2 个。
2. 花色符号上方同颜色的字就是点数。把它转正、放大，交给 iOS 的 Vision 文字识别读出来。
3. 另外把整张照片按 12 个角度转着交给 Vision 找点数字符，再到字符下方找花色，补上第一步漏掉的牌。
4. 按在照片里的位置分成上下左右四手牌。

拍照时让四家的牌摊开、牌角露出来，尽量正对着拍，光线均匀。

## 结构

- `BridgeReplay/Core`：牌、牌型解析、定约计分、出牌状态机、机器人、双明手封装、叫牌规则、练习牌库，
  以及照片识别（`OnDeviceCardReader.swift` 本地识别，`CardRecognition.swift` 按方向组装、排除法补牌）。
- `BridgeReplay/Core/PracticeDealsData.swift`：分级练习牌库，直接编在代码里。由 `Tools/practice-deals` 里的脚本生成（`embed.py` 把 JSON 写成 Swift）。
- `BridgeReplay/DDS`：Bo Haglund 与 Soren Hein 的 [DDS](https://github.com/dds-bridge/dds) 2.9.0 双明手求解器（Apache 2.0），
  通过 `DDSBridge.h` 和桥接头文件给 Swift 调用。对原始源码的改动见 `DDS/README-DDS.md`。
- `BridgeReplay/Store`：牌局与重打记录，保存为 App 文档目录里的 JSON。
- `BridgeReplay/Views`：SwiftUI 界面。

## 还没做

- 照片识别的准确度要靠真实照片来调；认错的牌可以在录入页点选修改。
- 叫牌练习目前是南北两家都由你叫、东西不叫；还没有叫牌体系提示和有对手争叫的练习。
